# Glimmer 主题精修：封面与实景一致性（2026-10-23）

## 判断

现有枫叶、樱花和篝火已有可辨认的方向。本轮保留叶形、花瓣数量、轨迹、火焰及构图；不为了制造变化重画它们。最明确的问题是雨后封面太淡、部分主题的三份底色配置不一致，以及主题选择面板与其他工具浮层的材质不同。

## 调整

- 枫叶、樱花、篝火、雨后、水波纹的底色集中到 `frontend/src/components/zen/sceneSurfaces.ts`。
- 主题实际场景、静态封面、切换时的不透明背景层引用同一份配置。雨后原先注册的是偏绿底色、实际是蓝白；水波纹注册的是平色、实际是径向渐变，现在按实际场景统一。
- 枫叶和樱花封面保留同一套叶形、花形，底色改为完整场景所用的渐变。
- 雨后封面在小尺寸下使用较宽的彩色光带，并调整取景位置；保留实际场景的轻淡光感，没有加饱和度滤镜、噪点或灰色云层。
- 水波纹封面仍是两组正圆俯视波纹，增加光侧与暗侧的细微变化，外圈更淡。实际水波动画未改。
- 清理重复的篝火封面缩放规则。
- 浅色主题选择面板使用上一轮的共用纸面浮层样式；深色选择面板保留深色适配。

## 验收

实际切换检查了雨后、枫叶、樱花、水波纹、篝火，截图位于 `docs/screenshots/2026-10-23/theme-refinement/`，结束后恢复 Waves。数据源、账号配置、收藏未改动。

61 项测试、代码检查、网页构建、插件构建、回归检查通过。新增一项回归测试：上述五个主题的实际场景和封面必须使用注册的不透明背景，防止后续再发生配置漂移。

本轮没有调整背景交接算法，也未声称完成所有主题组合、显卡和 Chrome 安装实例的无闪屏验收。当前检查依据本地网页版，未发布。

## 维护约定

1. 修改这五个主题的底色，先改共享配置，不在封面、CSS 和注册表分别复制渐变。
2. 小封面允许适当放大关键特征，但颜色与主体必须来自实际主题。
3. 预览保持静态；场景动画的节奏与数量保持独立，避免 hover 时同时播放十多个主题。
4. 优先保留已认可的设计；后续对运动的改动应有前后录屏，而不能只凭静态截图判断。

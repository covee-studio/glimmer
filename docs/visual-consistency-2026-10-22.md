# Glimmer 视觉一致性：第一轮（2026-10-22）

## 设计判断

先统一阅读之外的工具层。它应该安静、可读、可靠，不因打开不同弹窗而更换一套视觉语言。主题继续负责环境气氛，工具弹窗保持暖纸面；这不是把所有主题改成同一套颜色。

## 本轮完成

- 收藏、数据源、关于共用标题字号、标题与关闭按钮的排列、纸面、圆角及阴影。
- 关于页移除深色装饰图标，介绍全文、来源致谢及链接保留。
- 正文、辅助文字、线条、焦点与控件使用语义颜色，降低蓝灰与绿色混用。
- 关闭按钮统一为 40×40；图标按钮、连接按钮、输入框、主按钮与开关共用样式。
- hover 以轻微颜色变化为主，来源行保留柔和底色；阅读左右翻页按钮去掉放大反馈。
- 弹窗进入改为轻微位移与透明度变化，不再缩放正文；退出更及时。系统减少动态效果时取消这类位移与过渡。
- 数据源二级页采用淡入淡出；动画结束后才恢复焦点，返回后回到原连接按钮。实际往返已验证。
- 列表滚动条变细，固定滚动条占位，减少列表与空搜索结果之间的横向变化。

## 维护入口

| 内容 | 位置 | 规则 |
| --- | --- | --- |
| 颜色、圆角、阴影、控件与 hover | `frontend/src/assets/reading-ui.css` | 在这里修改语义变量和共用类，避免为单个弹窗增加新的色值与阴影。 |
| 关闭按钮 | `frontend/src/components/ui/CloseButton.tsx` | 保持标签名称、键盘焦点与点击区域一致。 |
| 弹窗和二级页动效 | `frontend/src/components/ui/usePanelMotion.ts` | 共用进出节奏及减少动态效果支持；不控制主题背景切换。 |
| 场景与阅读内容 | 原有主题组件、正文样式 | 保持独立，不把 UI 规范扩散成重画主题。 |

没有增加 UI 库或其他依赖，也没有引入通用组件框架。只抽取目前确实重复的规则。

## 实际验收

- 桌面检查：来源列表、微信读书空连接页、关于全文、最近列表及搜索无结果恢复。
- 375×667：来源列表与收藏列表均可操作，没有横向溢出。收藏弹窗左右边界 16、359，上下约 40、627；关闭按钮仍为 40×40。
- 深色背景：实际切到 Campfire，检查同一纸面弹窗的可读性；结束后恢复 Waves。
- 未输入密钥、未连接或断开账号、未清空历史或改变收藏；热更新浏览产生的最近记录保留。
- 60 项测试、代码检查、网页和插件构建、回归检查通过。此轮截图依据本地网页版，不代替安装后的 Chrome 验收、读屏认证或主题切换全组合验收。

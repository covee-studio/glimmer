# Glimmer 2.2.2 release candidate

## Scope

- Simplify Saved/Recent and source configuration presentation; preserve the full About introduction.
- Keep Chrome favorite sync opt-in and retain existing preferences. A single cloud button opens its switch; the web build remains local only.
- Restore switch thumb animation, soften source hover, and sequence palette dismissal before background dissolves.
- Keep Saved selected when removing the last favorite; retain Undo.
- No added extension permissions or changes to credential storage/sync payload scope.
